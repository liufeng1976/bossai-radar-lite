# BossAI Next Steps / 下一步去哪里

BossAI Radar Lite answers **what deserves attention**. It does not create a second execution platform. After Radar returns a deterministic decision, continue with the public BossAI component that matches the work.

BossAI Radar Lite 负责回答“什么值得做”，不创建第二套执行平台。Radar 给出确定性结论后，按任务类型进入对应 BossAI 公开能力。

## Decision → next action

| Radar decision | Recommended next action | BossAI public project |
| --- | --- | --- |
| `BUILD` | Turn validated demand into a governed execution plan, tasks, deliverables, acceptance criteria, and human-approval gates. | [BossAI Ecommerce Manager Skill](https://github.com/liufeng1976/bossai-ecommerce-ai-team-skill) |
| `BUILD` + developer/API product | Prototype the governed AI application with reusable contracts, Skills, Workflows, approval gates, local RAG, file parsing, and webhook security. | [BossAI OS Core](https://github.com/liufeng1976/bossai-os-core) |
| `BUILD` or `SELL_SERVICE` + content/video demand | Turn the validated topic or offer into a local Windows video workflow: script, authorized voice, talking avatar, subtitles/editing and export. | [BossAI Video Agent](https://github.com/liufeng1976/bossaios-com-video-agent) |
| `SELL_SERVICE` | Use the opportunity evidence to define a narrow service offer, then manage customer-service / ecommerce / sales / execution tasks with human approval. | [BossAI Ecommerce Manager Skill](https://github.com/liufeng1976/bossai-ecommerce-ai-team-skill) |
| `WATCH` | Keep collecting evidence. Do not promote the idea to a validated opportunity until deterministic evidence thresholds are met. | Stay in Radar Lite |
| `IGNORE` | Do not spend build or sales resources unless materially new evidence appears. | Stop / archive the opportunity |

## What is transferred

Prefer handing off evidence, not conclusions without provenance:

- opportunity title and Radar decision;
- source URLs and evidence excerpts;
- pain / willingness-to-pay / competition / urgency signals;
- target customer and proposed 7-day validation action;
- known uncertainty and missing evidence;
- explicit human-approval requirements for any external action.

Do **not** transfer passwords, API keys, cookies, private customer data, private logs, platform credentials, or other secrets through public GitHub issues or repository content.
