账户全景

外贸潜客 Account Review

把官网、业务渠道、历史贸易、Intelligence 与 Sales 审核放在同一条证据链里；不把历史行为或联系方式解释成当前购买意图。

老板决策留痕

记录本次账户决策

批准进入 Sales 或排除潜客前，记录主要理由和必要说明。系统会同时保存当时的证据摘要，但不会生成成交概率或自动执行 CRM/外联。

经营结果复核

确认这次执行实际产生了什么结果

Sales 结果只是员工报告。只有你在这里确认后，Radar 才会把结果标为已确认；金额永远不会从员工文本自动提取。

不填金额表示“结果已确认，但经营价值金额未知”。员工报告中的金额不会自动带入。

浏览器证据补全

补全 JavaScript 官网公开证据

Radar 不运行通用 Browser Agent。请在你控制的浏览器中打开目标官网，等待页面渲染完成后，把该页面的 rendered HTML 回填到这里。只接受同一官网域名，原始 HTML 不落库。
